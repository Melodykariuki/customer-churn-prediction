# Customer Churn Prediction System

## 1. Project Overview

The Customer Churn Prediction System is a machine learning application developed to predict whether a telecommunications customer is likely to leave a service provider.

The system uses the IBM Telco Customer Churn dataset and a Logistic Regression classification model to analyse customer information and generate predictions.

## 2. Project Objectives

- Analyse customer data to identify patterns associated with customer churn.
- Develop a machine learning model for predicting customer churn.
- Evaluate and compare machine learning models.
- Develop an interactive web application for making customer churn predictions.
- Provide insights that can help telecommunications companies improve customer retention.

## 3. Dataset

The project uses the IBM Telco Customer Churn dataset, which contains 7,043 customer records and information about customer demographics, subscribed services, contracts and billing.

**Target variable:** Churn (Yes/No).

## 4. Technologies Used

- Python
- Google Colab
- Pandas
- Scikit-learn
- Streamlit
- Joblib
- GitHub

## 5. Machine Learning Models

Two classification algorithms were trained and evaluated:

1. Logistic Regression
2. Random Forest

Logistic Regression was selected for deployment because it achieved better overall evaluation results in the project.

## 6. Application Features

- Customer information input.
- Customer service and billing information input.
- Machine learning-based churn prediction.
- Estimated churn probability.
- Visual presentation of prediction results.

## 7. Installation and Usage

Clone the repository:

```bash
git clone https://github.com/Melodykariuki/customer-churn-prediction.git
```

Navigate to the project folder:

```bash
cd customer-churn-prediction
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
